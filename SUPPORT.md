# Getting help with MjPetz

- **Something is broken:** [open a bug report](https://github.com/mjcity/mjpetz-app/issues/new?template=bug_report.yml). Include your MjPetz version (Settings › About), your system and the agent you were using.
- **An idea or a wish:** [ask for a feature](https://github.com/mjcity/mjpetz-app/issues/new?template=feature_request.yml).
- **A question, or anything you would rather keep private:** email [support@mjpetz.xyz](mailto:support@mjpetz.xyz).
- **A security problem:** see [SECURITY.md](SECURITY.md). Please do not post it as an issue.

Issues here are public. Never paste API keys, passwords, tokens or private chats into one.

Answers to common questions are in the [FAQ](README.md#faq) and on [mjpetz.xyz](https://mjpetz.xyz).
