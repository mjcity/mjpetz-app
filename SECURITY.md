# Security

If you find a security problem in MjPetz, please email **[support@mjpetz.xyz](mailto:support@mjpetz.xyz)** with "Security" in the subject. Do not open a public issue for it.

Please include:

- your MjPetz version (Settings › About) and your computer (Windows, Mac or Linux, and its version)
- which agent was involved, if any
- what you did, what happened, and what you expected
- how bad you think it is, and whether it can be reproduced

Never send real API keys, passwords or tokens, even in a report. If a key may have leaked, revoke it with the service that issued it first.

## Supported versions

MjPetz is in public beta. Security fixes go into the newest version, listed at the top of the [changelog](CHANGELOG.md). Please check that you are on the newest version before you report.

## What happens next

We will reply as soon as we can, keep you posted while we fix it, and credit you in the release notes if you would like that.

The privacy policy is at [mjpetz.xyz/privacy](https://mjpetz.xyz/privacy).
